## 🛠️ Tech Stack

- **Core**: React 18, JavaScript (ESNext), HTML5
- **Build Tool**: Vite
- **Styling**: Vanilla CSS (Custom Design System, Dark Mode, Glassmorphism)
- **Animations**: Framer Motion
- **Icons**: Lucide React (`lucide-react`) & React Icons (`react-icons/fi`)
- **Contact Service**: FormSubmit API

## 💻 Local Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/devanshh18/portfolio.git
   cd portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
